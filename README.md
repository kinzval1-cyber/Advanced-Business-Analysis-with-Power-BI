# Superstore Sales & Profitability Analysis

## Project Overview

A Power BI business intelligence project using the **Superstore Sales Dataset** to analyze sales performance, profitability, products, customers, regions, and discount impact.

The project builds on a previous exploratory analysis and focuses on turning data into **business insights and actionable recommendations**.

## Tools Used

- Power BI
- DAX
- Power Query
- Microsoft Excel

## Key Areas Analyzed

- Sales & Profit Trends
- Regional Performance
- Customer Segments
- Product & Sub-Category Performance
- Discount & Profitability
- Monthly & Quarterly Analysis
- KPI Development

## Key Findings

- Sales and profit increased consistently, with **Q4 recording the strongest performance**.
- **West** generated the highest regional profit, while **Central** generated the lowest.
- **Consumer** was the strongest customer segment by profit.
- **Tables** generated high sales but recorded a significant loss.
- Higher discounts were associated with weaker profitability, particularly for Tables.
- **Copiers** showed strong profitability despite lower sales compared with some other sub-categories.
